Here is the complete, combined application in a single file. This code merges both the **EIR to BEP Simulator (Gateway 01)** and the **Forma Execution Checklist (Gateway 02)** into one seamless Single Page Application (SPA). When the student successfully passes the BEP validation and clicks to initialize Autodesk Forma, the website will instantly transition to the execution checklist without needing to load a new page.
